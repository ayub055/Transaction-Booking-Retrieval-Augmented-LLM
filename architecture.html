Train
Supervised Contrastive (SupCon) Training
SupCon loss — uses ALL in-batch positives (vs. triplet's single pair)
Per-class temperature scaling — minority classes get sharper gradients
Gradual BERT unfreezing — top semantic layers fine-tuned first
Inverse-frequency class weighting — sqrt dampening to prevent explosion
Semi-hard negative mining — focuses on boundary-crossing negatives
Class-balanced batch sampling — equal class representation per batch
IndicBERT v2 fine-tune
Encoder
FusionEncoder
IndicBERT (768-dim) + Categorical Embedding (4-dim) + Numeric (1-dim)
→ MLP + LayerNorm → 256-dim L2-normalised vector
FP16 precision · Trained weights saved as fusion_encoder_best.pth
Index
Stratified FAISS Index Build
Encode all 35K golden records with trained FusionEncoder
Max 500 exemplars / class — greedy farthest-point sampling
Prevents majority classes drowning minority categories
Build HNSW graph · compute per-class prototype centroids
Save: golden_records.faiss + _metadata.pkl
OOD
OOD Threshold Calibration
Uses real 'other' transactions (rgs.csv, 192 rows) → F1-optimise threshold
Fallback: 95th percentile of within-corpus nearest-neighbour distances
Threshold saved to _metadata.pkl · Used at inference to flag unknowns
