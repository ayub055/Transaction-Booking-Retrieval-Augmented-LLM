2 FusionEncoder Training
IndicBERT (fine-tuned, not frozen) encodes Hindi/English banking text.
Fused with categorical embedding (UPI/NEFT/IMPS/RTGS → 4-dim) + numeric scaler (amount).
MLP + LayerNorm → 256-dim L2-normalised vector.
Training: SupCon loss · inv-freq weighting · class-balanced batches · gradual BERT unfreezing
IndicBERT fine-tuned SupCon loss 256-dim output
★   OUR EXTENSION
3 Stratified FAISS Index
HNSW graph built from encoded vectors.
Max 500 exemplars/class via greedy farthest-point sampling — prevents majority classes crowding out rare ones.
Amazon paper: flat index, no class balancing — fails on imbalanced data
HNSW · 50× faster search Balanced per class
★   OUR EXTENSION
4 Per-class Prototypes
L2-normalised centroid vector computed for each of the 43 categories.
Frequency-bias immune — blended with k-NN votes at inference (α = 0.6).
